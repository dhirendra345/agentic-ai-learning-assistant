# Agentic AI Research & Learning Assistant

An AI-powered research assistant built using:

- FastAPI
- LangChain
- LangGraph
- ChromaDB
- OpenAI/Llama
- Streamlit
- Docker

## Features

- PDF/PPT/DOCX Upload
- Chat with Documents (RAG)
- Research Report Generation
- MCQ Generation
- Summarization
- Web Search Integration
- Multi-Agent Workflow
